# Changelog

The project follows Semantic Versioning.

## [1.0.0] - 2026-07-28

### Release summary

- Laravel 12 foundation with authentication, Admin/Editor authorization, notifications, cached settings, responsive components, AdminLTE administration, security headers, branded errors, and themes.
- Normalized product, service, and portfolio management with categories, media, publishing, featured content, public catalogues, SEO, and dashboards.
- Lead management for contact, demo, and quote requests with history, notes, notifications, bulk operations, and protected attachments.
- Blog and knowledge center with categories, tags, scheduled publishing, downloads, FAQs, RSS, sitemap integration, and structured metadata.
- CMS for home, about, contact, navigation, footer, business hours, branding, social links, analytics, mail, integrations, maintenance, and global SEO.
- Shared media optimization and cleanup, public/private storage separation, cache invalidation, query optimization, accessibility, responsive UI, and security hardening.
- Order and money management, centralized communications, reusable media, activity auditing, profiles, system health, and lightweight role and permission management.
- Commercial browser installer with requirement checks, database validation, Administrator creation, optional official demo content, production optimization, and a permanent installation lock.
- Feature coverage for foundation, products, services, leads, portfolio, blog, CMS, orders, finance, communications, users, roles, media, installer, and settings.

### Known limitations

- Scheduled publishing requires an external scheduler every minute.
- Asynchronous processing requires a separately supervised queue worker.
- Image optimization requires PHP GD or Imagick.
- TLS, backups, mail delivery, monitoring, and process supervision are deployment-operator responsibilities.
